## Rules

- keep all examples generic
- no real credentials or private data
- no project-specific brands, domains, hostnames or paths
- preserve DE/EN documentation consistency where practical
- update schemas when examples introduce new fields
- prefer small, reviewable changes
- call out breaking changes
- legal/compliance text is guidance and evidence structure, never a guarantee
- security-sensitive recommendations must preserve least privilege

## Agent compatibility

Commands and templates should remain understandable for Claude Code, ChatGPT Codex and agents that only read Markdown instructions.

Do not require proprietary agent behavior for core usage.
