# Compliance Toolkit

This directory provides a project-neutral structure for documenting legal and regulatory research.

It is not legal advice.

## Goals

- prefer official primary sources
- record jurisdiction and review date
- separate source facts from project interpretation
- turn findings into concrete engineering or product actions
- track unresolved questions
- review time-sensitive sources regularly

## Recommended structure

Each project may maintain:

- legal source registry
- processor/subprocessor register
- retention matrix
- DPIA screening
- release compliance checklist
- public transparency documents
- internal evidence and review records

## Privacy

Do not store identity documents, customer case files, credentials or private legal correspondence in a public repository.

Use references to protected storage when evidence itself is sensitive.
