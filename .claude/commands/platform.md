# /platform

Use the MGD-Plattform-Builder rules from this repository.

Arguments: `$ARGUMENTS`

If no mode is supplied, start with a read-only audit. For a new project use `briefing` first.

Modes: `audit`, `briefing`, `init`, `template`, `release`, `module <name>`, `backoffice`, `compliance`, `security`, `update`.

Read `AGENTS.md`, `WIKI/README.md` and `platform/SKILL.md` before acting. The briefing questions are in `platform/BRIEFING.md` and `registry/briefing.yml`.
