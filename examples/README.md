# Example Project Profiles

These files demonstrate how different project types can describe themselves using the same foundation.

They are synthetic examples only.

- `general-platform.yml`
- `game.yml`
- `community.yml`
- `creator.yml`
- `ecommerce.yml`

Copy an example into your project as `MGD_PLATFORM.yml` and customize it.

Do not copy example settings blindly into production.
