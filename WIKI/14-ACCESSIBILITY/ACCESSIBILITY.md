# Accessibility

Accessibility should be part of design and release review, not a later skin.

## Baseline checks

- keyboard operation
- visible focus
- semantic structure
- labels and names
- sufficient contrast
- touch target size
- error identification
- reduced-motion support where relevant
- screen reader testing for core workflows

## Backoffice

Admin tools also matter. Dense tables and modals should remain operable with keyboard and assistive technology.

## Market compliance

Legal accessibility requirements depend on service type, market and organization status. Track these through the compliance system rather than assuming one global rule.
