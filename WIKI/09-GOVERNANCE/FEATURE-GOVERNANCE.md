# Feature Governance

Every significant feature should answer the same questions.

## Product

- purpose
- users
- scope
- cost/storage/support impact

## Data & Privacy

- personal data
- purpose
- retention
- deletion
- visibility
- data-subject rights
- DPIA screening

## Security

- authentication
- authorization
- abuse
- rate limits
- secrets
- audit
- safe failure
- recovery

## Compliance

- markets/jurisdictions
- sector/platform rules
- youth/accessibility/consumer impact

## Operations

- monitoring
- backup
- migration
- rollback
- staging
- feature flag

## Documentation

- user/admin docs
- agent docs
- task tracking
- changelog
