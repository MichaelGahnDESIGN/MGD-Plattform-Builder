# Incident Response

## Phases

1. Detect
2. Contain
3. Preserve evidence
4. Analyze
5. Recover
6. Communicate
7. Postmortem

## Incident record

Track:

- incident ID
- detection time
- affected systems
- affected data classes
- suspected entry point
- containment
- rotated credentials
- legal/privacy assessment
- user communication
- recovery steps
- follow-up actions

## Immediate containment examples

- revoke sessions
- disable compromised account
- rotate token/key
- disable risky endpoint
- maintenance mode
- stop uploads/payments if integrity is uncertain

## Evidence

Use UTC timestamps and preserve originals when evidence matters.

Do not paste sensitive evidence into public issues.

## Privacy incidents

Security incidents involving personal data require a separate privacy/legal assessment according to the applicable jurisdiction.
