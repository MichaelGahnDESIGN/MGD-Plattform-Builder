# Creator / Publishing Domain Pack

## Typical modules

- creator profiles
- teams/organizations
- uploads
- content versions
- rights declarations
- moderation
- publishing schedule
- subscriptions/entitlements
- analytics
- support

## Key risks

- rights ownership disputes
- impersonation
- unsafe uploads
- content moderation
- payout identity verification
- data retention

## Recommendation

Separate creator identity from login account so multiple people can manage one creator entity and one user can manage multiple creator entities.
