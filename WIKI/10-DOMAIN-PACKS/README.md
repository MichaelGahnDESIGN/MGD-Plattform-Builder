# Domain Packs

Domain packs provide additional planning defaults for common project categories.

They do not change the core foundation.

## Included starter packs

- [Game](GAME.md)
- [Community](COMMUNITY.md)
- [Creator / Publishing](CREATOR.md)
- [E-Commerce](ECOMMERCE.md)

## Pack contents

A pack may define:

- typical modules
- common entities
- common permissions
- abuse patterns
- privacy risks
- operational needs
- release gates

## Combining packs

A project may combine packs.

Example: a game with a creator marketplace may use Game + Creator + E-Commerce.

Resolve conflicts explicitly in the project's own architecture docs.
