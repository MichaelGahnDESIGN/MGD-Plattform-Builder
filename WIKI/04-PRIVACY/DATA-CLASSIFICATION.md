# Data Classification

A practical classification helps turn abstract privacy/security goals into access rules.

## Suggested classes

### Public

Intentionally public data.

### Internal

Operational data not intended for the public.

### Private

User/account data visible only to the subject and necessary system roles.

### Sensitive

Support content, contractual information, security-related data and other higher-risk personal data.

### Restricted

Secrets, recovery material, identity evidence or highly sensitive case records.

## Controls by class

Define per project:

- who may read
- who may write
- encryption
- audit requirement
- export behavior
- backup handling
- retention
- masking/redaction

## Principle

Admin status alone should not automatically bypass classification.
