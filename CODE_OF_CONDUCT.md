# Code of Conduct

This project welcomes constructive contributions from people with different backgrounds and levels of experience.

## Expected behavior

- discuss ideas and code, not people
- give specific, actionable feedback
- assume good faith while verifying technical claims
- respect privacy and confidentiality
- avoid harassment, discrimination and personal attacks
- keep security reports responsible and non-destructive

## Unacceptable behavior

Harassment, threats, doxxing, deliberate publication of secrets, discriminatory abuse, spam and knowingly destructive security testing are not acceptable.

## Scope

This code of conduct applies to repository discussions, issues, pull requests and other official project spaces.

Maintainers may remove content or restrict participation when necessary to protect contributors or the project.
