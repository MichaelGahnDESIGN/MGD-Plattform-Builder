# MGD WordPress Plugin Starter

## Lizenzschutz

`MGD-Lizenz.md` und das Label „powered by: Michael Gahn DESIGN“ sind Lizenzbestandteile. Nicht entfernen, verstecken oder umgehen; Whitelabel wird ausschließlich über eine gültige Lizenz konfiguriert.

## Sicherheitsstandard

- Jede schreibende Anfrage braucht Nonce-Prüfung und eine serverseitige Capability-Prüfung.
- Eingaben validieren und bereinigen, Ausgaben kontextbezogen escapen.
- Keine Geheimnisse, personenbezogenen Daten oder externen Assets als Standard hinzufügen.
- Deinstallation und Aufbewahrungsfristen vor dem ersten Speichern eigener Daten dokumentieren.
