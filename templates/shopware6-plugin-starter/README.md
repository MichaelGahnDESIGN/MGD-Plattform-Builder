# MGD Shopware 6 Plugin Starter

Der Starter liefert Composer-Metadaten, eine leere Plugin-Klasse und getrennte Administration-Design-Tokens. Er enthält absichtlich weder Migration, Controller noch Datenzugriff.

Nächste Schritte: Namespace/Name anpassen, Ziel-Shopware-Version festlegen, Datenmodell und Migration planen, danach ACL, Services und Storefront getrennt ergänzen. Tests müssen Installation/Aktivierung, Migrationen, Berechtigungen und den realen Verkaufskanal abdecken.
