# Feature Governance Checklist

Feature:

Owner:

Status:

## Product

- [ ] purpose documented
- [ ] user roles identified
- [ ] MVP scope defined
- [ ] cost/storage/traffic impact considered

## Data & Privacy

- [ ] data categories identified
- [ ] purpose and legal basis reviewed where applicable
- [ ] retention/deletion path defined
- [ ] data subject rights impact checked
- [ ] privacy by default considered
- [ ] DPIA screening completed if needed

## Security

- [ ] authentication requirements
- [ ] authorization/capabilities
- [ ] input/output validation
- [ ] rate limits/abuse
- [ ] audit/security events
- [ ] secret handling
- [ ] safe failure behavior

## Compliance

- [ ] relevant jurisdictions
- [ ] sector/platform rules
- [ ] youth/accessibility/consumer rules if relevant
- [ ] legal review gate defined if needed

## Operations

- [ ] monitoring
- [ ] backup impact
- [ ] migration
- [ ] rollback
- [ ] staging test
- [ ] feature flag if high risk

## Documentation

- [ ] user/admin docs
- [ ] agent/project docs
- [ ] TODO/issue updated
- [ ] changelog when user-visible
