# MGD JTL-Shop 5 Plugin Starter

Dieses Gerüst trennt Bootstrap, Metadaten, Backend-Assets und spätere Templates. Es ist absichtlich noch **kein veröffentlichtes JTL-Plugin**: vor einer Installation müssen Plugin-ID, unterstützte Shopversion und die konkrete JTL-Plugin-Schnittstelle geprüft werden.

Vor dem Implementieren Datenfluss, Rechte, Cache-Auswirkung und Rückfallweg dokumentieren. Nach einer Testinstallation Pluginverwaltung, Frontend-Template, Backend-Rechte und die betroffenen Cache-Bereiche getrennt prüfen.
