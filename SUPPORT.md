# Support

This repository is community-oriented and does not provide guaranteed commercial support.

## Questions

Use GitHub Discussions if enabled, otherwise open an issue with the `question` label.

## Bugs

For reproducible repository problems, open an issue and include:

- affected file/version
- expected behavior
- actual behavior
- minimal reproduction

## Security

Follow `SECURITY.md`. Do not post exploit details publicly.

## Project-specific implementation help

The foundation can guide architecture, but maintainers cannot guarantee compatibility with every hosting provider, legal jurisdiction or technology stack.
