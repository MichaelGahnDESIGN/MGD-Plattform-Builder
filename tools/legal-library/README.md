# Legal Library Viewer

A zero-build, static viewer for the machine-readable legal-source model.

## Use

1. Copy this folder into your project.
2. Replace the synthetic data in `legal-sources.example.js`.
3. Open `index.html` or serve it through your local docs server.
4. Keep the JSON registry in sync with `compliance/schema/legal-source.schema.json`.

## Security and privacy

The viewer is intended for public/non-sensitive legal research metadata.

Do not place private legal correspondence, identity documents, case files or credentials into the dataset.

## Legal note

The viewer organizes research. It does not provide legal advice or certify compliance.
